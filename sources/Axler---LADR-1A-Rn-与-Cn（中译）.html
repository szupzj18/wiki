LADR 1A Rⁿ 与 Cⁿ（中译）

译自 Linear Algebra Done Right, 4th edition 第 1 章 §1.A（书页 1–11）。定义编号与原书一致。

第 1 章 向量空间（章引言）

线性代数是研究有限维向量空间上的线性映射的学科。最终我们会学会这些术语的含义。本章我们将定义向量空间并讨论其基本性质。

在线性代数中，把复数与实数一起研究会产生更好的定理和更深刻的洞见。因此我们从介绍复数及其基本性质开始。

我们将把平面和普通空间的例子推广到 Rⁿ 和 Cⁿ，再进一步推广到向量空间的概念。我们将会看到，向量空间是一个带有加法和数乘运算、并满足自然代数性质的集合。

然后是子空间——它对向量空间的作用类似于子集对集合的作用。最后讨论子空间的和（类似于子集的并）与子空间的直和（类似于不相交集合的并）。

题图：笛卡尔向瑞典女王克里斯蒂娜讲解他的工作。向量空间是笛卡尔 1637 年发表的”用两个坐标描述平面”这一方法的推广。

§1.A　Rⁿ 和 Cⁿ

复数

你应已熟悉实数集 R 的基本性质。复数的发明是为了让我们能对负数取平方根：假定 −1 有一个平方根，记作 i，它遵守通常的算术规则。以下是正式定义。

1.1 定义：复数，C

  • 复数是有序对 (a, b)，其中 a, b ∈ R，但我们写作 a + bi。
  • 所有复数的集合记作 C：C = {a + bi : a, b ∈ R}。
  • C 上的加法与乘法定义为：

(a+bi)+(c+di)=(a+c)+(b+d)i

(a+bi)(c+di)=(ac−bd)+(ad+bc)i

其中 a, b, c, d ∈ R。

若 a ∈ R，我们把 a + 0i 等同于实数 a，因此把 R 看作 C 的子集。通常把 0 + bi 简写为 bi，把 0 + 1i 简写为 i。

符号 i 最早由欧拉于 1777 年用来表示 √−1。

为理解复数乘法定义的动机：假装已知 i² = −1，用通常的算术规则推导出两复数乘积的公式，再用该公式验证确实有 i² = −1。

不要记忆复数乘法公式——随时可由 i² = −1 和算术规则（见 1.3）重新推导。下例演示这一过程。

1.2 例子：复数算术

(2+3i)(4+5i)=2⋅(4+5i)+(3i)(4+5i)=8+10i+12i−15=−7+22i

1.3 复数算术的性质

  • 交换律：对所有 α, β ∈ C，α + β = β + α 且 αβ = βα。
  • 结合律：对所有 α, β, λ ∈ C，(α + β) + λ = α + (β + λ) 且 (αβ)λ = α(βλ)。
  • 单位元：对所有 λ ∈ C，λ + 0 = λ 且 λ·1 = λ。
  • 加法逆元：对每个 α ∈ C，存在唯一的 β ∈ C 使 α + β = 0。
  • 乘法逆元：对每个 α ≠ 0 的 α ∈ C，存在唯一的 β ∈ C 使 αβ = 1。
  • 分配律：对所有 λ, α, β ∈ C，λ(α + β) = λα + λβ。

这些性质由实数的常见性质及复数加乘定义证明。下例演示乘法交换律的证明，其余留作练习。

1.4 例子：复数乘法交换律

设 α = a + bi，β = c + di。则

αβ=(ac−bd)+(ad+bc)i,βα=(ca−db)+(cb+da)i

由实数加法和乘法的交换律即得 αβ = βα。∎

1.5 定义：−α、减法、1/α、除法

设 α, β ∈ C：

  • −α 表示 α 的加法逆元，即满足 α + (−α) = 0 的唯一复数。
  • 减法：β − α = β + (−α)。
  • 对 α ≠ 0，1/α 表示 α 的乘法逆元，即满足 α(1/α) = 1 的唯一复数。
  • 除法：β/α = β(1/α)。

1.6 记号：F

本书中 F 始终表示 R 或 C（字母 F 来自 field/域）。证明一个涉及 F 的定理，就同时知道它对 R 和 C 都成立。F 的元素称为标量（scalar），用于强调”数”的身份，以区别于即将定义的向量。

对 α ∈ F 和正整数 m，αᵐ 表示 α 自乘 m 次。由此 (αᵐ)ⁿ = αᵐⁿ，(αβ)ᵐ = αᵐβᵐ。

列表

1.7 例子：R² 与 R³

  • R²（可想象为平面）= {(x, y) : x, y ∈ R}
  • R³（可想象为普通空间）= {(x, y, z) : x, y, z ∈ R}

1.8 定义：列表、长度

  • 设 n 为非负整数。长度为 n 的列表是 n 个元素的有序汇集（元素可以是数、其他列表或更抽象的对象）。
  • 两列表相等 ⟺ 长度相同且元素按相同顺序排列。

长度为 n 的列表也称 n 元组，形如 (z₁, …, zₙ)。形如 (x₁, x₂, …) 的无限序列不是列表。长度为 0 的列表 () 也算列表，以使定理没有平凡例外。

列表与集合的两点不同：列表中顺序重要、重复有意义；集合中顺序与重复无关紧要。

1.9 例子：列表与集合

  • 列表 (3, 5) ≠ (5, 3)，但集合 {3, 5} = {5, 3}。
  • 列表 (4, 4) ≠ (4, 4, 4)（长度不同），但集合 {4, 4} = {4, 4, 4} = {4}。

Fⁿ

1.10 记号：n　本章余下部分固定一个正整数 n。

1.11 定义：Fⁿ、坐标

Fn={(x1​,…,xn​):xk​∈F, k=1,…,n}

称 xₖ 为第 k 个坐标。F = R 且 n = 2 或 3 时，与通常的 R²、R³ 一致。

1.12 例子：C⁴ = {(z₁, z₂, z₃, z₄) : z₁, z₂, z₃, z₄ ∈ C}

书外推荐：Edwin A. Abbott《平面国》（1884），有趣地描述了 R² 生物如何感知 R³，可帮助想象四维以上空间。

n ≥ 4 时无法把 Rⁿ 想象成物理对象；n ≥ 2 时人脑也无法完整想象 Cⁿ。但代数运算在 Fⁿ 中与在 R²、R³ 中一样容易。

1.13 定义：Fⁿ 中的加法（按坐标相加）

(x1​,…,xn​)+(y1​,…,yn​)=(x1​+y1​,…,xn​+yn​)

1.14 Fⁿ 中加法的交换律　若 x, y ∈ Fⁿ，则 x + y = y + x。

证明　设 x = (x₁, …, xₙ)，y = (y₁, …, yₙ)。则

x+y=(x1​+y1​,…,xn​+yn​)=(y1​+x1​,…,yn​+xn​)=y+x

第二、四个等号用 Fⁿ 加法定义（1.13），第三个等号用 F 中加法交换律。∎

用单个字母 x 表示向量、xⱼ 表示其坐标；能不写坐标就不写。

1.15 记号：0　0 = (0, …, 0)：左边是向量（Fⁿ 的元素），右边每个 0 是标量。靠上下文区分。

1.16 例子　“对所有 x ∈ Fⁿ，x + 0 = x” 中的 0 只能是向量——因为”向量加标量”尚未定义。

几何直观（R² 中）：R² 的元素 v = (a, b) 可看作点，也可看作从原点指向 (a, b) 的箭头（向量）。箭头可平行移动（长度、方向不变）而仍视为同一向量。

经济模型可有数千个变量 x₁, …, x₅₀₀₀，必须在 R⁵⁰⁰⁰ 中工作——几何方法失效，但代数方法有效。这就是”线性代数”得名的原因。图画只是理解的辅助，不能替代严格的数学。

向量加法的几何解释：把 v 平移使其起点与 u 的终点重合，则 u + v 是从 u 的起点指向 v 的终点的向量（三角形法则）。

1.17 定义：Fⁿ 中的加法逆元，−x

−x 是满足 x + (−x) = 0 的向量。若 x = (x₁, …, xₙ)，则 −x = (−x₁, …, −xₙ)。

几何上：R² 中 −x 与 x 长度相同、方向相反。

1.18 定义：Fⁿ 中的数乘

λ(x1​,…,xn​)=(λx1​,…,λxn​),λ∈F

数乘 = 标量 × 向量 → 向量。（对比：R²/R³ 中的点积是 向量 × 向量 → 标量，其推广在第 6 章。）

几何上（R² 中）：λ > 0 时 λx 与 x 同向、长度放大 λ 倍；λ < 0 时 λx 与 x 反向、长度为 |λ| 倍。

题外话：域

域是至少含两个不同元素 0 和 1 的集合，带有满足 1.3 全部性质的加法和乘法。R、C、有理数集 Q 都是域；{0, 1}（规定 1 + 1 = 0）也是域。

本书只用 R 和 C，但大部分定义、定理和证明对任意域无需修改即成立（第 6、7 章内积空间除外）。以”F = C”为假设的结论，通常可换成”F 为代数闭域”（每个非常数多项式都有零点）。少数结论（如习题 1.C 第 13 题）还需 1 + 1 ≠ 0。

习题 1.A

  1. 证明：对所有 α, β ∈ C，α + β = β + α。
  2. 证明：对所有 α, β, λ ∈ C，(α + β) + λ = α + (β + λ)。
  3. 证明：对所有 α, β, λ ∈ C，(αβ)λ = α(βλ)。
  4. 证明：对所有 λ, α, β ∈ C，λ(α + β) = λα + λβ。
  5. 证明：对每个 α ∈ C，存在唯一的 β ∈ C 使 α + β = 0。
  6. 证明：对每个 α ≠ 0 的 α ∈ C，存在唯一的 β ∈ C 使 αβ = 1。
  7. 证明 (−1 + √3 i)/2 是 1 的立方根。
  8. 找出 i 的两个不同的平方根。
  9. 求 x ∈ R⁴ 使 (4, −3, 1, 7) + 2x = (5, 9, −6, 8)。
  10. 解释为何不存在 λ ∈ C 使 λ(2 − 3i, 5 + 4i, −6 + 7i) = (12 − 5i, 7 + 22i, −32 − 9i)。
  11. 证明：对所有 x, y, z ∈ Fⁿ，(x + y) + z = x + (y + z)。
  12. 证明：对所有 x ∈ Fⁿ 和所有 a, b ∈ F，(ab)x = a(bx)。
  13. 证明：对所有 x ∈ Fⁿ，1x = x。
  14. 证明：对所有 λ ∈ F 和所有 x, y ∈ Fⁿ，λ(x + y) = λx + λy。
  15. 证明：对所有 a, b ∈ F 和所有 x ∈ Fⁿ，(a + b)x = ax + bx。
