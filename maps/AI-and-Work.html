AI and Work

AI 怎样改变知识工作、编程和设计工作。分节沿用 index 的三个主题组：AI 与知识工作、组织，AI 编程，AI 设计工具。

Core Ideas

Verification is the bottleneck

  • AI-native knowledge work is a verification problem before it is an intelligence problem — the synthesis: what is missing is a feedback loop that shows whether output is right, not more raw intelligence.
  • Verification quality determines how safely work can be delegated — work moves to agents as fast as its output can be checked quickly and reliably.
  • Work becomes easier to automate when evaluation criteria are externalized — once standards live in tests, rubrics or checklists, automation can read them.
  • Weak feedback loops push humans back into low-leverage review work — when output is hard to verify, humans end up re-checking every intermediate step.
  • Humans should supervise AI from leveraged positions rather than sit inside every loop — set direction, review outcomes and step in at high-leverage points.
  • Managers in AI-native organizations may become designers of verification systems — management shifts toward standards, exceptions, checkpoints and escalation paths.

Context and organizations

  • AI knowledge work improves when context is consolidated — knowledge work stays hard for AI while context is scattered across tools, documents and unwritten memory.
  • Context consolidation and verifiability reinforce each other — unified context makes output easier to judge; clear evaluation shows which context matters.
  • Organizations can use AI as a load-bearing context layer — AI that carries context could take over coordination now done by meetings and hierarchy.
  • Most AI adoption still imitates old tools instead of redesigning workflows — new capability gets wrapped in familiar interfaces, which delays deeper redesign.
  • New infrastructure changes scale before it changes culture — a new infrastructure layer changes scale and rhythm first; new norms show up later.

AI coding

  • LLM coding usefulness came from crossing a reliability threshold, not raw capability — models became useful once they were reliable enough to run inside automated feedback loops.
  • Near-term AI productivity gains come from retooling the industry rather than better models — the next gains come from changing how software gets built, not from smarter models alone.
  • AI productivity claims conflict between anecdotal reports and formal studies — anecdotes report 10x; formal studies find small or no measurable gains.
  • AI coding tools create a K-shaped workforce split between augmented engineers and those unable to leverage them — the tools widen existing skill gaps instead of flattening them.
  • A working implementation now signals twenty percent done rather than eighty percent — a working version used to mean most of the job was done; now it is the start.
  • LLM-generated code is locally functional but globally incoherent — passable in isolation, architecturally inconsistent across a codebase.
  • Effective AI coding treats output as hypotheses to be validated rather than code to review — treat model output as hypotheses checked by executable tests, not as code to read line by line.
  • Spec-driven development is rising as AI shifts coding toward writing clear requirements — the model fills every ambiguity, so the work moves into unambiguous specifications.
  • The cognitive load of reviewing AI output is real and different from writing code — reviewing generated code is a different kind of effort from writing it.

AI design tools

  • Conversational design tools widen exploration by lowering prototype cost — cheaper prototypes let teams try more directions before committing.
  • Design systems compound when AI can apply them automatically — a design system is worth more when the tool applies it to every new draft by default.
  • Design handoff improves when design intent travels with implementation context — hand off the reasoning and interaction intent, not only a static artifact.
  • AI creative workflows get stronger when import refinement export and handoff stay connected — the gain comes from collapsing several workflow stages into one surface.
