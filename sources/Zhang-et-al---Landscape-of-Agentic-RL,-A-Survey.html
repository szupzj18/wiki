The Landscape of Agentic Reinforcement Learning for LLMs, A Survey

TMLR 01/2026 · 500+ 篇文献

Summary / 摘要

EN: This survey formalizes Agentic RL — the paradigm shift from treating LLMs as static sequence generators to treating them as learnable policies embedded in sequential decision-making loops. The core theoretical move is casting conventional preference-based RLHF as a degenerate single-step MDP (one prompt, one response, one scalar reward, full observability) versus Agentic RL as a temporally extended POMDP (dynamic world state, partial observations, text ∪ environment actions, step-wise sparse+dense rewards). On this foundation it builds a twofold taxonomy: one by agentic capability (planning, tool use, memory, reasoning, self-improvement, perception) and one by application domain. Its central thesis: RL is the mechanism that transforms these capabilities from static, heuristic modules into adaptive, robust behavior. It closes with three frontier challenges — trustworthiness, scaling agentic training, and scaling agentic environments.

ZH: 本文把”智能体强化学习”（Agentic RL）形式化为一次范式转移：LLM 不再是静态的序列生成器，而是嵌入序列决策回路中的可学习策略。核心理论动作是把传统偏好对齐（RLHF）视为退化的单步 MDP（一个提示、一个回答、一个标量奖励、完全可观测），而 Agentic RL 是时间延展的 POMDP（动态世界状态、部分可观测、文本∪环境动作、逐步的稀疏+稠密奖励）。在此之上建立双重分类法：按智能体能力（规划、工具使用、记忆、推理、自我改进、感知）与按应用领域。中心论点：RL 是把这些能力从静态启发式模块转变为自适应鲁棒行为的关键机制。结尾提出三大前沿挑战——可信性、规模化训练、规模化环境。

Key Takeaways / 核心要点

  • EN: PBRFT (RLHF/DPO) is a degenerate MDP with horizon T=1; Agentic RL is a POMDP with T>1, partial observability, and an action space of text ∪ environment-changing actions. ZH: 偏好对齐是视界 T=1 的退化 MDP；Agentic RL 是 T>1 的 POMDP，部分可观测，动作空间是文本∪改变环境的动作。

  • EN: RL’s role across all six capabilities is the same: replace static heuristics with learned policies — e.g. memory becomes an RL-controlled subsystem deciding what to store, retrieve, and forget, not a passive vector store. ZH: RL 在六大能力中扮演同一角色：用学习到的策略替换静态启发式——例如记忆变成由 RL 控制、决定存什么/取什么/忘什么的子系统，而非被动向量库。

  • EN: Planning splits into two paradigms — RL as external guide (a learned value function steering MCTS, as in RAP/LATS) vs RL as internal driver (the LLM itself as policy, as in ETO/VOYAGER); the future is a meta-policy that chooses when to deliberate. ZH: 规划分两种范式——RL 作外部引导（学习价值函数指导 MCTS，如 RAP/LATS）与 RL 作内部驱动（LLM 本身即策略，如 ETO/VOYAGER）；未来是一个决定”何时深思”的元策略。

  • EN: Tool use evolves in three stages: ReAct-style imitation (SFT/prompting, brittle) → tool-integrated RL (outcome-driven optimization; emergent self-correction even from base models) → long-horizon multi-turn TIR, whose bottleneck is temporal credit assignment and reward hacking. ZH: 工具使用经历三阶段：ReAct 式模仿（SFT/提示，脆弱）→ 工具集成 RL（结果驱动优化，甚至从基座模型涌现出自纠错）→ 长程多轮 TIR，瓶颈是时序信用分配与奖励作弊。

  • EN: Self-improvement has three levels: verbal self-correction (ephemeral, no gradients), RL-internalized self-correction (durable, in-weights), and iterative self-training (self-play, execution-guided curricula, collective bootstrapping — R-Zero, Absolute Zero, SiriuS). ZH: 自我改进有三个层次：口头自纠（临时、无梯度）、RL 内化的自纠（持久、写入权重）、迭代自训练（自博弈、执行引导课程、集体自举——R-Zero、Absolute Zero、SiriuS）。

  • EN: Reasoning is framed as fast (System 1) vs slow (System 2); the open problem is training slow-thinking reliably in agentic settings without overthinking, pointing to adaptive test-time scaling. ZH: 推理被框定为快（系统1）与慢（系统2）；开放问题是在智能体场景中可靠训练慢思考且避免过度思考，方向是自适应测试时扩展。

  • EN: Trustworthiness is worse for agents than for chatbots: RL turns the agent from a passive victim of manipulation into an active reward-seeking exploiter — it will learn and entrench unsafe paths if they pay. Mitigation = sandboxing + process rewards that penalize unsafe intermediate steps + adversarial training inside the RL loop. ZH: 智能体的可信问题比聊天机器人更严重：RL 把智能体从被动的操纵受害者变成主动追逐奖励的利用者——只要不安全路径有回报，它就会学会并固化。缓解 = 沙箱 + 惩罚不安全中间步骤的过程奖励 + RL 回路内的对抗训练。

  • EN: Outcome-only RL imposes a “hallucination tax”: it degrades abstention, so agents answer unanswerable questions rather than saying “I don’t know”; SFT on solvable+unsolvable mixes restores epistemic humility. ZH: 纯结果 RL 会征收”幻觉税”：它削弱拒答能力，智能体宁可胡答也不说”不知道”；用可解+不可解混合数据做 SFT 可恢复认知谦逊。

  • EN: Scaling environments means treating the environment as optimizable, not static: automated reward design (explorer agents generate trajectories to train reward models) + automated curriculum generation (EnvGen-style procedural content targeting the agent’s weaknesses) form a self-improving training flywheel. ZH: 规模化环境意味着把环境当作可优化对象而非静态背景：自动化奖励设计（探索者智能体生成轨迹训练奖励模型）+ 自动化课程生成（EnvGen 式针对弱点的程序化内容）构成自我改进的训练飞轮。

MDP 对比（Table 1）

维度PBRFT (RLHF/DPO)Agentic RL

奖励单标量 r(a)逐步 R(s_t, a_t)，稀疏任务奖励 + 稠密子奖励
目标E[r(a)]E[Σ γ^t R(s_t, a_t)]

能力分类法（Section 3）

  1. Planning — 外部引导（MCTS+学习价值函数）vs 内部驱动（LLM 即策略）；前瞻： deliberation 与 intuition 的综合，元策略治理深思过程
  2. Tool Use — ReAct 模仿 → TIR 结果驱动 RL → 长程多轮 TIR（时序信用分配是核心未解问题）
  3. Memory — RAG 式被动存储 → RL 控制存取忘 → 跨 episode 持续适应
  4. Self-Improvement — 口头自纠 → RL 内化自纠 → 迭代自训练（自博弈/执行课程/集体自举）；前瞻：反思能力本身的元进化
  5. Reasoning — 快思考 vs 慢思考；agentic 场景下慢思考的训练稳定性与 overthinking
  6. Perception — 被动感知 → 主动视觉认知（grounding 驱动、工具驱动、生成驱动）

三大挑战（Section 6）

  • Trustworthiness: security（间接提示注入、多智能体通信投毒、RL 放大的奖励黑客）、hallucination（幻觉税）、sycophancy（RLHF 本身激励谄媚）
  • Scaling Training: 计算（Agent RL Scaling Law：更长训练视界提升工具使用频率与推理深度）、模型规模（熵崩塌风险）、数据（跨域 RL 有协同也有干扰）、效率
  • Scaling Environments: 环境从静态变为可协同进化的系统；自动化奖励 + 自适应课程 = 训练飞轮
