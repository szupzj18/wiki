LADR 1A 习题解答

配套翻译：§1.A Rⁿ 与 Cⁿ（中译）

证明风格遵循原书：每一步等号都注明依据（定义或实数性质）。

1. 证明：对所有 α, β ∈ C，α + β = β + α。

设 α = a + bi，β = c + di，其中 a, b, c, d ∈ R。则

α+β=(a+bi)+(c+di)=(a+c)+(b+d)i（复数加法定义 1.1）

=(c+a)+(d+b)i（实数加法交换律）

=(c+di)+(a+bi)=β+α（复数加法定义 1.1）

∎

2. 证明：对所有 α, β, λ ∈ C，(α + β) + λ = α + (β + λ)。

设 α = a + bi，β = c + di，λ = e + fi。则

(α+β)+λ=((a+c)+(b+d)i)+(e+fi)=((a+c)+e)+((b+d)+f)i

α+(β+λ)=(a+bi)+((c+e)+(d+f)i)=(a+(c+e))+(b+(d+f))i

由实数加法结合律，(a+c)+e = a+(c+e) 且 (b+d)+f = b+(d+f)，故两式相等。∎

3. 证明：对所有 α, β, λ ∈ C，(αβ)λ = α(βλ)。

设 α = a + bi，β = c + di，λ = e + fi。由复数乘法定义（1.1）：

αβ=(ac−bd)+(ad+bc)i

(αβ)λ=[(ac−bd)e−(ad+bc)f]+[(ac−bd)f+(ad+bc)e]i

βλ=(ce−df)+(cf+de)i

α(βλ)=[a(ce−df)−b(cf+de)]+[a(cf+de)+b(ce−df)]i

比较实部（用实数乘法对加法的分配律、结合律、交换律展开）：

(ac−bd)e−(ad+bc)f=ace−bde−adf−bcf

a(ce−df)−b(cf+de)=ace−adf−bcf−bde

两者相等。虚部同理：

(ac−bd)f+(ad+bc)e=acf−bdf+ade+bce

a(cf+de)+b(ce−df)=acf+ade+bce−bdf

两者相等。故 (αβ)λ = α(βλ)。∎

4. 证明：对所有 λ, α, β ∈ C，λ(α + β) = λα + λβ。

设 λ = e + fi，α = a + bi，β = c + di。则 α + β = (a + c) + (b + d)i，于是

λ(α+β)=[e(a+c)−f(b+d)]+[e(b+d)+f(a+c)]i

另一方面，

λα=(ea−fb)+(eb+fa)i,λβ=(ec−fd)+(ed+fc)i

λα+λβ=(ea−fb+ec−fd)+(eb+fa+ed+fc)i

由实数分配律，e(a+c) − f(b+d) = ea + ec − fb − fd，且 e(b+d) + f(a+c) = eb + ed + fa + fc，故两式相等。∎

5. 证明：对每个 α ∈ C，存在唯一的 β ∈ C 使 α + β = 0。

存在性： 设 α = a + bi，取 β = (−a) + (−b)i。则

α+β=(a+bi)+((−a)+(−b)i)=(a−a)+(b−b)i=0

唯一性： 设 α + β = 0 且 α + γ = 0。则

β=β+0=β+(α+γ)=(β+α)+γ=(α+β)+γ=0+γ=γ

（依次用了：0 是加法单位元、α + γ = 0、加法结合律、交换律、α + β = 0、0 是单位元。）∎

6. 证明：对每个 α ≠ 0 的 α ∈ C，存在唯一的 β ∈ C 使 αβ = 1。

设 α = a + bi ≠ 0，则 a² + b² > 0（a, b 不全为 0）。

存在性： 取

β=a2+b2a−bi​=a2+b2a​−a2+b2b​i

则

αβ=a2+b2(a+bi)(a−bi)​=a2+b2a2−(bi)2​=a2+b2a2+b2​=1

（注意 (a+bi)(a−bi) = a² − abi + abi − b²i² = a² + b²。）

唯一性： 设 αβ = 1 且 αγ = 1。由复数乘法交换律（1.4）、结合律：

β=β⋅1=β(αγ)=(βα)γ=(αβ)γ=1⋅γ=γ

∎

7. 证明：ω = (−1 + √3 i)/2 是 1 的立方根。

先算 ω²：

ω2=4(−1+3​i)2​=41−23​i+3i2​=4−2−23​i​=2−1−3​i​

于是

ω3=ω2⋅ω=4(−1−3​i)(−1+3​i)​=41−(3​i)2​=41+3​=1

故 ω³ = 1。∎

8. 找出 i 的两个不同的平方根。

设 (a + bi)² = i，其中 a, b ∈ R。展开得

a2−b2+2abi=0+1i

比较实部虚部：a² − b² = 0 且 2ab = 1。由 a² = b² 得 a = ±b。

  • 若 a = b，则 2a² = 1，a = ±1/√2，得到两个根：

2​1+i​,2​−1−i​

  • 若 a = −b，则 −2a² = 1，在实数范围内无解。

验证：((1+i)/√2)² = (1 + 2i + i²)/2 = 2i/2 = i。✓

故 i 的两个不同的平方根为 (1 + i)/√2 和 −(1 + i)/√2。

9. 求 x ∈ R⁴ 使 (4, −3, 1, 7) + 2x = (5, 9, −6, 8)。

两边减去 (4, −3, 1, 7)：

2x=(5−4, 9−(−3), −6−1, 8−7)=(1,12,−7,1)

故

x=(21​, 6, −27​, 21​)

10. 解释为何不存在 λ ∈ C 使 λ(2 − 3i, 5 + 4i, −6 + 7i) = (12 − 5i, 7 + 22i, −32 − 9i)。

若存在这样的 λ，由第一个坐标：

λ(2−3i)=12−5i⟹λ=2−3i12−5i​=(2−3i)(2+3i)(12−5i)(2+3i)​=4+924+36i−10i−15i2​=1339+26i​=3+2i

用第二个坐标检验：

(3+2i)(5+4i)=15+12i+10i+8i2=7+22i✓

用第三个坐标检验：

(3+2i)(−6+7i)=−18+21i−12i+14i2=−32+9i=−32−9i✗

同一个 λ 无法同时满足三个坐标，故不存在这样的 λ。

11. 证明：对所有 x, y, z ∈ Fⁿ，(x + y) + z = x + (y + z)。

设 x = (x₁, …, xₙ)，y = (y₁, …, yₙ)，z = (z₁, …, zₙ)。则

(x+y)+z=((x1​+y1​)+z1​,…,(xn​+yn​)+zn​)

=(x1​+(y1​+z1​),…,xn​+(yn​+zn​))=x+(y+z)

其中每个坐标的等式用 F 中加法的结合律。∎

12. 证明：对所有 x ∈ Fⁿ 和所有 a, b ∈ F，(ab)x = a(bx)。

(ab)x=((ab)x1​,…,(ab)xn​)=(a(bx1​),…,a(bxn​))=a(bx1​,…,bxn​)=a(bx)

第二个等号用 F 中乘法结合律，最后一个等号用数乘定义（1.18）。∎

13. 证明：对所有 x ∈ Fⁿ，1x = x。

1x=(1x1​,…,1xn​)=(x1​,…,xn​)=x

其中 1xₖ = xₖ 是因为 1 是 F 的乘法单位元。∎

14. 证明：对所有 λ ∈ F 和所有 x, y ∈ Fⁿ，λ(x + y) = λx + λy。

λ(x+y)=(λ(x1​+y1​),…,λ(xn​+yn​))=(λx1​+λy1​,…,λxn​+λyn​)=λx+λy

第二个等号用 F 中的分配律。∎

15. 证明：对所有 a, b ∈ F 和所有 x ∈ Fⁿ，(a + b)x = ax + bx。

(a+b)x=((a+b)x1​,…,(a+b)xn​)=(ax1​+bx1​,…,axn​+bxn​)=ax+bx

第二个等号用 F 中的分配律。∎

学习笔记

  • 第 1–6 题的模板：设出实部虚部 → 套复数运算定义 → 用实数性质 → 套回定义。
  • 第 5、6 题的唯一性证明用了同一个技巧：要证唯一，就设两个对象都满足条件，再证明它们相等（“唯一性 = 任意两个相等”）。
  • 第 7、8 题展示了复数的几何：三个立方根均匀分布在单位圆上（120° 间隔），两个平方根也是（90° 间隔）。
  • 第 10 题说明：数乘要求同一个标量作用于所有坐标，逐个坐标凑出来的 λ 必须一致。
  • 第 11–15 题与第 1–4 题结构完全平行：Fⁿ 的性质归约为 F 的性质——这正是 1.B 节公理化的动机。
